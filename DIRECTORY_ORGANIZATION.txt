Directory Organization Summary
Repository: spin-glass-benchmarks
Snapshot: 2026-09-03

Purpose
This repository contains curated spin-glass benchmark instances, PyTorch-based
reference solvers, reproducible experiment tooling, tests, documentation, and
supporting literature. The main workflow is: use or generate instances, run
solvers through the experiment framework, compare against baselines, and publish
or inspect results through the docs.

Top-Level Layout

README.md
  Main project overview, quick start instructions, solver/instance summary, and
  links to the documentation site.

instances/
  Canonical benchmark instance library. Files are organized by problem family,
  then by system size, with one coupling text file per seeded instance.

  Current instance inventory on disk:
    sk/      N50, N100, N200, N300                 40 files
    ea2d/    N100, N256, N1024, N2304              40 files
    ea3d/    N512, N1000, N1728, N2744             40 files
    rrg/     N50, N100, N150, N200, N300           50 files
  Total current main instance files: 170

generators/
  Instance generation code and related tests. Includes generators for SK, EA,
  RRG, and XORSAT-style instances, plus shared pairwise instance/file-format
  helpers.

solvers_v2/
  Modern solver implementation package. This is the main refactored solver
  codebase.

  Important subdirectories:
    src/        Shared I/O, schedules, observables, reproducibility, results,
                updates, and other core utilities.
    common/     Algorithm implementations shared across families, including
                simulated annealing, population annealing, parallel tempering,
                greedy, and global annealing.
    families/   Family-specific adapters for SK, EA, RRG, and XORSAT.
    envs/       Solver environment lock/specification files.

experiments/
  Reproducible experiment framework and example experiment folders. The shared
  framework code lives in experiments/src/, while researcher-specific runs live
  under experiments/<researcher>/<experiment_name>/.

  Notable contents:
    src/                         Config schemas, runner, CLI, result handling,
                                 machine specs, and analysis utilities.
    biazzin/sk_ga_initial/       Example SK/global-annealing experiment.
    biazzin/ea3d_ga_pa_paper_pilot/
                                 Example EA3D global-vs-population annealing
                                 pilot with plotting and result artifacts.

tests/
  Main pytest suite for the refactored solvers and generators. The README in
  this directory explains baseline parity tests and when to regenerate baselines.

tests_data/
  Stable development-time fixtures. Contains small instance snapshots and JSON
  solver baselines used to detect unintended numerical changes in solvers_v2.

docs/
  Quarto documentation site source. Includes problem definitions, file format
  notes, implementation status, architecture, solver/instance documentation,
  results pages, references, styling, and documentation assets.

environments/
  Conda environment specifications for the main workflows:
    solvers-core-gpu.yml   GPU solver/experiment environment.
    solvers-core-cpu.yml   CPU-only solver/experiment environment.
    generators.yml         Reproducible instance generation environment.

scripts/
  Utility scripts for regenerating systematic instances, example instances, and
  solver baseline JSON files.

solvers/
  Older system-specific solver implementations grouped by problem family. This
  mirrors legacy and modern optimization scripts for SK, EA3D, and XORSAT.

systematic_solver/
  Older MLMC optimization project folders for SK and XORSAT. These contain
  legacy packages, modern optimization scripts, README files, and related data.

example_notebook/
  Demonstration notebook area with example data, solver code copies, generated
  images, and a performance comparison image.

tests_plots/
  Plotting scripts and generated figures for checking coupling distributions and
  colormaps.

papers/
  Reference PDFs related to spin-glass, XORSAT, population annealing, quantum
  heuristic optimization, and equation planting benchmark literature.

.github/
  GitHub workflow configuration, including documentation publishing.

.vscode/
  Workspace editor settings.

Supporting Top-Level Files
  ENVIRONMENT_SETUP.md          Additional environment setup notes.
  EXPERIMENT_SCRIPTS.md         Notes for experiment scripts.
  EXPERIMENTS_IMPLEMENTATION.md Implementation notes for the experiment system.
  LICENSE                       Project license.
  .gitignore                    Ignored local/generated files.

How The Pieces Fit Together
  1. Benchmark instances live in instances/ and are loaded by solvers through
     solvers_v2/src/io.py.
  2. New or regenerated instances come from generators/ and scripts/.
  3. Solver algorithms live in solvers_v2/common/ and are exposed through
     family adapters in solvers_v2/families/.
  4. Reproducible experiment runs are configured and launched through
     experiments/.
  5. Tests in tests/ compare solver behavior against fixtures and baselines in
     tests_data/.
  6. Documentation in docs/ explains the mathematical problems, file formats,
     architecture, implementation status, and results.
  7. Legacy/reference implementations remain in solvers/, systematic_solver/,
     and example_notebook/ for comparison, provenance, and migration context.
